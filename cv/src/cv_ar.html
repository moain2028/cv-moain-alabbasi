نبذة مهنية

مهندس برمجيات أصمم أنظمة الأعمال وأبنيها وأسلّمها كاملة بنفسي، من قاعدة البيانات إلى الواجهة إلى النشر. سلّمت لعملاء في السعودية واليمن أنظمة نقاط بيع وERP، وأنظمة حضور وانصراف، ومنصات إشعارات ووصول بعيد آمن، وتطبيقات جوال تعمل بدون إنترنت، وأنظمة ذكاء اصطناعي متعددة الوكلاء، ومواقع سريعة مهيأة لمحركات البحث. أكتب اختبارات آلية لكل نظام، وأوثّق قراراتي التقنية، وأسلّم العميل الشفرة المصدرية كاملة. أعمل عن بعد بالكامل وبنفس توقيت السعودية.

المهارات التقنية

لغات البرمجة: TypeScript, JavaScript, Python, Go, Dart, Kotlin, SQL, PL/SQL, PHP

الخوادم (Backend): NestJS, Node.js, FastAPI, Hono, Express, Prisma, Drizzle, REST, BullMQ, Redis, WebSockets

الواجهات: React 19, Next.js, Angular 22, Tailwind CSS, PWA، تطبيقات تعمل بدون إنترنت، واجهات عربية RTL، إتاحة WCAG 2.1 AA

الجوال: Flutter لأندرويد، Kotlin + Jetpack Compose، مسح الباركود، الطباعة الحرارية عبر البلوتوث

قواعد البيانات: PostgreSQL, Oracle, MySQL, SQLite، وترحيل البيانات من الأنظمة القديمة والمغلقة

الذكاء الاصطناعي والوكلاء: ربط النماذج اللغوية (OpenAI, Anthropic, Gemini)، LangGraph, LangChain، تنسيق الوكلاء المتعددين، البحث الهجين وRAG، خوادم MCP، قراءة الصور OCR، معالجة اللغة العربية

الأمن السيبراني: مراكز العمليات الأمنية Wazuh SIEM, Suricata, YARA, MITRE ATT&CK، التحليل الجنائي الرقمي، الوصول البعيد بنموذج Zero Trust

النشر والجودة: Docker, GitHub Actions, Cloudflare, Vercel, Linux VPS, pytest, Vitest, Playwright

نمو المواقع: السيو التقني، مؤشرات Core Web Vitals، Google Search Console، Google Ads API، تحسين التحويل، الامتثال لنظام حماية البيانات الشخصية
